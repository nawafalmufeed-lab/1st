===========================================
Project Information:
- Framework: React 18 + TypeScript
- Build Tool: Vite
- Styling: Tailwind CSS
- Charts: Recharts
- Icons: Lucide React
- Routing: React Router v6
===========================================

- Reviewer: username: reviewer1, password: password
