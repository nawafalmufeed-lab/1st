# 🏫 نظام المدفوعات - مدارس

## 📋 نظرة عامة

نظام إدارة مدفوعات المدارس - تطبيق ويب متكامل لإدارة ومراجعة واعتماد التحويلات المالية للمدارس.

## ✨ المميزات

### 🎨 التصميم
- ✅ واجهة مستخدم عصرية وجذابة
- ✅ دعم كامل للغة العربية (RTL)
- ✅ تصميم متجاوب (Responsive) لجميع الأجهزة
- ✅ Sidebar ثابت للتنقل السهل
- ✅ رسوم متحركة سلسة

### 📊 الوظائف الرئيسية

#### 1. لوحة التحكم (Dashboard)
- ملخص مالي شامل
- إحصائيات حسب الحالة
- آخر التحويلات
- رسوم بيانية تفاعلية

#### 2. إدارة التحويلات
- عرض جميع التحويلات في جدول مفصل
- بحث وتصفية متقدمة
- تحديد واختيار متعدد
- عرض تفاصيل كل تحويل
- تصدير البيانات إلى Excel

#### 3. حاسبة الرسوم
- حساب رسوم التنشيط (BR-01)
- حساب رسوم المعاملات (BR-02)
- دعم جميع وسائل الدفع:
  - مدى (0.85%)
  - فيزا/ماستركارد (1.17%)
  - تمارا (10%)

#### 4. إدارة المستخدمين والصلاحيات
- مراجع (Reviewer)
- معتمد (Approver)
- مصفوفة صلاحيات واضحة

## 🚀 كيفية الاستخدام

### 1. فتح التطبيق
افتح ملف `login.html` في المتصفح

### 2. تسجيل الدخول
- اختر نوع المستخدم (مراجع أو معتمد)
- أدخل بيانات الدخول التجريبية
- اضغط "تسجيل الدخول"

### 3. التنقل
استخدم القائمة الجانبية للتنقل بين الأقسام:
- لوحة التحكم
- التحويلات
- حاسبة الرسوم
- المستخدمين

## 🎯 الحالات (Status Flow)

```
ST-01: بانتظار المراجعة  →  ST-02: قيد المراجعة  →  ST-03: معتمد  →  ST-04: تم التحويل
                                                                    ↓
                                                            ST-05: فشل التحويل
```

## 💰 قواعد العمل (Business Rules)

### BR-01: رسوم التنشيط الثابتة
- **المبلغ:** 85 ر.س
- **الشرط:** عقد تنفيذي (Executive) + أول دفعة فقط
- **التطبيق:** مرة واحدة لكل طالب

### BR-02: رسوم المعاملات (نسبة متغيرة)
- **مدى:** 0.85%
- **فيزا/ماستركارد:** 1.17%
- **تمارا:** 10%
